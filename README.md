# Guesstimate

A multiplayer console trivia guessing game written in Java and playable directly in the browser via `ttyd` and OpenJDK 17.

## How to Play Online

1. Open the web link.
2. Enter the number of players and number of questions.
3. Guess the answers — the closest guess gets the highest score!
